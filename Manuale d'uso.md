# Sistema di Gestione Spese Personali

## Requisiti:

- Interprete: Python 3.x

- Librerie standard utilizzate: sqlite3 (per l'interazione con il database). Non è richiesta l'installazione di librerie esterne.

## Istruzioni per eseguire il programma:

- Istruzioni di compilazione: Essendo scritto in Python, il codice non richiede alcuna compilazione preventiva.

- Istruzioni di avvio: Aprire il terminale, posizionarsi all'interno della cartella `src` e avviare lo script tramite l'interprete Python.

- Comando esatto da eseguire: *python main.py*
